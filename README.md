# HabitFlow Monorepo

Production-minded Habit Tracker app (PWA) with React + TypeScript frontend and Node.js + Express + MongoDB backend.

## Apps

- `apps/web`: Vite + React + Tailwind + Zustand + React Router + i18next + PWA
- `apps/api`: Express + TypeScript + Mongoose + JWT auth

## Quick start

```bash
# 1) API
cd apps/api
npm install
npm run dev

# 2) Web
cd ../web
npm install
npm run dev
```

See `docs/IMPLEMENTATION_PLAN.md` for architecture and delivery plan.
